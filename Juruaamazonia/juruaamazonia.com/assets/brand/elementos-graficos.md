# Elementos Gráficos — Juruá Log

Este documento define os elementos visuais complementares da identidade da Juruá Log.

## Objetivo

Apoiar a identidade visual da landing page sem poluir o layout.

Os elementos devem reforçar:
- logística
- Amazônia
- cadeia de frios
- operação
- confiabilidade

## Tipos de elementos

### Patterns

Uso:
- fundos leves
- seções institucionais
- detalhes no hero
- rodapé

Evitar:
- excesso de repetição
- baixa legibilidade do texto

### Ícones

Uso:
- cards de serviços
- diferenciais
- fluxo operacional

Ícones recomendados:
- armazém
- temperatura
- caminhão
- rota
- monitoramento
- segurança
- sustentabilidade

### Shapes

Uso:
- compor fundos
- criar movimento visual
- destacar CTAs

Formas recomendadas:
- linhas curvas inspiradas em rios
- setas discretas de fluxo logístico
- blocos geométricos arredondados

### Texturas

Uso:
- fundos muito sutis
- áreas de destaque
- conexão com Amazônia

Texturas recomendadas:
- mapa topográfico
- rios
- vegetação abstrata
- ruído leve

## Diretrizes

- Usar sempre com baixa opacidade
- Não competir com o conteúdo
- Priorizar verde, cinza e tons neutros
- Manter estética B2B
- Evitar aparência turística ou artesanal

## Aplicação na landing

### Hero
Pode usar shape ou linha de rota em baixa opacidade.

### Serviços
Usar ícones simples e consistentes.

### Como funciona
Usar linha ou seta para representar fluxo.

### Sustentabilidade
Pode usar textura amazônica sutil.

### Rodapé
Pode usar pattern discreto da marca.

## Regra principal

Elemento gráfico deve ajudar a leitura, não decorar por decorar.
